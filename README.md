# 合金机兵 2581 独立复刻

本仓库保存项目的可维护源码、原资料处理工具、独立 Native 宿主、测试和构建脚本，用于 Git 版本管理。

## 范围

- `src/`：项目基础设施与原地图/碰撞适配。
- `native-host/`：Cocos Native 宿主和本地离线入口。
- `tools/`、`scripts/`：原资料导入、资源处理、宿主打包与签名适配工具。
- `tests/`：基础设施、导航、Native 宿主边界和资源打包回归。
- `android/`、配置文件：保留的 Android/Expo 工程骨架。

## 本地输入

原 APK、恢复后的完整运行资源、私有运行分析报告、设备截图/日志和本地构建产物不进入 Git 仓库。它们由 `.gitignore` 排除；需要构建完整 Native 开发包时，按内部交接记录准备对应的只读输入和本地工具环境。

当前代码仍处于持续复刻与验收阶段。开发包、局部场景通过记录和私有设备证据不代表完整流程或最终发行版本已经完成。
